# Just Another ARK Server Manager (JAASM)

Cross-platform ARK: Survival Ascended dedicated server manager for Windows and Linux.

## Phase 1

- Detect Windows/Linux
- Select an existing SteamCMD installation
- Install SteamCMD from Valve's official CDN
- Validate SteamCMD
- Persist local JAASM settings
- Enable/disable the optional Web GUI setting

> Phase 1 is bootstrap functionality. ASA server installation and management follows in Phase 2.
